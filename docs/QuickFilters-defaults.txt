; Conveyor Belt Quick Filters - custom filters for the Input Hopper and Filter windows
;
; Save your own file as  %localappdata%\Whiskerwood\Saved\mods\QuickFiltersConfig\QuickFilters.txt
; (the name must end in .txt, not .txt.txt). It is read after the built-in list below:
;   - a line with the same name as a built-in filter replaces it
;   - 'Name =' with nothing after the = removes that filter
;   - new names are added at the end of the list
; Changes are picked up when you load a save.
;
; Example QuickFilters.txt - copy these lines (without the leading '; ') into your own file:
;
;   [presets]
;   Fuel stuff   = coal, fuel, wood        ; NEW button, added at the end of the list
;   Stone + ore  = stone, @ore, coal       ; REPLACES the built-in 'Stone + ore'
;   All food     =                         ; REMOVES the built-in 'All food' button
;   Metal bars   =                         ; REMOVES the built-in 'Metal bars' button
;
;   To remove a built-in button: write its name exactly as it shows on the button, then '=' and nothing else.
;   Your own file only needs the lines you want to change; everything else keeps the built-in list below.
;
; Format:   Filter name = token, token, token
;   resource id     e.g. stone, copperore, wheat  (list below)
;   @category       every resource in that window category, e.g. @ore, @rawFood (list below)
;   *               every resource
;   start the value with -  to make the button only turn resources OFF, e.g.  No food = -@rawFood, @foodTier1
; Clicking a filter toggles it: if all its resources are on they are turned off, otherwise they are turned on.
; Everything else stays as it is. Resources a window doesn't have are skipped.
; Spaces and upper/lower case don't matter; ; or # starts a comment (also at the end of a line).
;
